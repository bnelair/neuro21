
# Neuro Format for 21st Surgery

A scalable data format for large scale iEEG recordings supporting high volume data with random access.

## Data Format Requirements
- Scalability
- Random Access
- Streaming Capability
- Support for multiple parallel read processes
- Existing Free Viewer
- Integrity check
- Support in Python and Matlab

- This means a directory structure. This requires a tool to tarball the directory structure into a single file 
 and facilitate sharing.
